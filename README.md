# Diary App

A personal diary web app built with C# and ASP.NET Core (Razor Pages).

## Features

- Write, edit and delete diary entries
- Entries are listed newest first
- Data is stored in a SQLite database using Entity Framework Core

## Tech stack

C#, ASP.NET Core Razor Pages, Entity Framework Core, SQLite, Bootstrap

## Run it locally

1. Install the .NET SDK (version 10)
2. Clone this repository
3. Run `dotnet run` in the project folder
4. Open the address shown in the terminal (for example http://localhost:5233)
